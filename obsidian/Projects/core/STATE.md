# KERN — сквозной прототип 0.1.0

Rust1.96/Windows11. IM2480→redb→отдельный processor→параметры→uPlot/CSV/backup. Единственный писатель состояния — ядро, публикация после disk ack; рабочий цикл и графики раздельны. Новый профиль --storage redb: Immediate,CRC событий,16МиБ cache,порог файла4ГиБ. KJN backend/reader/старый комплект сохранены, смешивать backend в профиле нельзя; R2-импорт впереди.

Источник im2480: эксклюзивный COM,FC03,0009=0,постоянные слоты,6типизированных каналов/модуль; до96каналов/источник в резерве100×10. Не весь кадр. Missing по модулю, bounded повтор той же batch. Локальный config.json не Git, прежние настройки сохранены, эмулятор не менялся.

Карты linear-v1: неизменяемые ревизии,загрузка/активация,raw с активной revision; параметры со ссылкой на raw/карту/алгоритм. Исторический replay,устойчивая позиция,отказ неверного/старого результата. Maps≤256,params≤32; multi-input/stateful/осреднения пока нет. serde_json float_roundtrip обязателен,побитовая регрессия65536кодов. Свежесть от исходного входа,не от времени пересчёта.

kern-shell native обязателен desktop; charts — отдельный Rust loopback HTTP-host с отдельным ключом и app-окном установленного Edge/Chrome; JS/CSS/uPlot1.6.32 локально. Это временный host, не финальный WebView. UI close не останавливает запись. Веб управляет только заданными действиями. LAN/интернет/роли N2–N4 не реализованы (NETWORK_PLAN).

CSV/backup отдельные процессы,CRC/позиции,сохранение незавершённого хвоста. restore→новый профиль,ошибка оставляет import-incomplete. Копия на том же диске; может отставать от redb,полный drain/периоды обычного/быстрого потока впереди. Надзор processor/csv/backup:3запуска/60с→safe mode; lease15с/нет прогресса20с,только свои Child. Явный stop подавляет restart.

Контракт/приёмка: docs/PROTOTYPE.md,CORE_VALIDATION.md. dist/Kern-Prototype-0.1.0/Start-Kern.cmd; карты ТЕСТОВЫЕ.

HTTP10035 исправлен. UI: черновик параметров,таблица/график точек,JSON. А1–А3: отображение0–12В↔0–65535,физически не проверено. Колесо обратно/плавно,кэш/до30fps. График калибровки: pan/±/fit,сетка по осям,только вид. 20новых+9прежних UI,6transport,независимый расчёт. Заменён только charts,карты/приём сохранены.

Не приняты: слабыеПК/Win10/macOS/GPU/24–72ч/power-loss/полныйC2. Далее: шкалаАЦП,история/replay/drain/периоды,источники; сеть. Пути ASCII; старые приборы/профили не трогать; разговорные ориентиры не расшифровывать.
