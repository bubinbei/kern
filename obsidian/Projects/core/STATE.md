# KERN — начало независимой реализации

Новый репозиторий/корневой коммит, без прежнего runtime-кода и Git-истории. Есть согласованная архитектура/план, собственные утверждённые SVG/палитра, инструменты контекста/переводов; работающего приложения ещё нет. MIT; происхождение: docs/MATERIALS.md.

Цель — лёгкое надёжное ядро Rust. Сначала Windows10x64 и C0–C2 без GUI, затем интерпретатор, форматы, приборы, оболочка/графики по одному с отказной регрессией. macOS/другие ОС позднее. Стенды: Windows Intel «4125» (модель уточнить), Mac2012/macOS; испытаний ещё нет.

Две таблицы + упорядоченные события; стабильные ID, резерв100 адресов/экземпляр, первоначально до10 экземпляров, передаются только занятые.1COM=1экземпляр, второй экземпляр на другом порту. Ядро — единственный писатель авторитетного состояния. Карты в ядре, семантика/кеш у интерпретатора; save≠activate, активация по границе последовательности, expected revision/job version/snapshot+events.

Обязательный журнал хранит raw/результаты/версии, не зависит от экспортёра. Полные карты по изменению. Надзор heartbeat+worker-marker+progress; bounded restart, replay с историческими картами/состоянием, собственные позиции писателей без дублей/перестановок. Приём≠фиксация. Потери/качество явные, очереди ограничены. Оболочка — отдельный обязательный клиент, измерения через неё не идут. Графики сначала библиотека оболочки; скрытые/idle без постоянного repaint.

Стиль: Керн/KERN, три слоя, Ember/Gruvbox; assets/kern.svg и kern-theme.json. Сохранены требования плотного читаемого UI/клетчатой заливки, реализация впереди. Помощь до альфы отложена.

Разговорная «Белая» — ориентир; фиксировать собственные требования KERN без названий/ссылок/расшифровки прозвищ. При необходимости: «программа с белым интерфейсом». Канон AGENTS/MATERIALS.

Следующее: C0 — минимальный Rust-workspace/контракт и независимый генератор, затем C1 сырой журнал/чтение. Канон docs/ARCHITECTURE.md, приёмка docs/ROADMAP.md. Не трогать старые процессы, профили и реальные приборы. Документы не доказывают устойчивость/ресурсы.
