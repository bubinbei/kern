# Происхождение и публикация

Репозиторий начинается с нового корневого коммита. Старые Git-объекты, runtime-код, бинарники, схемы чужих файлов, исследования, рабочие конфигурации, измерения и журналы разработки не импортируются.

Архитектура и план написаны для KERN по требованиям владельца. Трёхслойный SVG, иллюстрации README и цветовые токены — собственные утверждённые материалы проекта. Перенесены только самостоятельно написанные MIT-инструменты контекста/сверки переводов и их тесты; сохранено исходное уведомление об авторстве в LICENSE. Это проверяемая граница переноса, а не утверждение о юридической экспертизе любых будущих материалов.

Новый код — MIT; сторонние зависимости требуют отдельной проверки лицензии и происхождения. Не добавлять внешние исходники, ресурсы, спецификации или совместимые форматы без зафиксированного источника/основания. Не маскировать запрещённый материал переименованием или упаковкой. Синтетические тесты должны иметь собственный генератор.

Перед публикацией: проверить diff, индекс и всю новую историю; исключить локальные пути, учётные данные и реальные данные. Логотип и палитра задают стиль, иллюстрация README не является снимком работающей программы.
