# Стиль KERN

Утверждено 23.10.2026: имя **Керн / KERN**, знак из трёх слоёв, янтарная палитра **Ember / Gruvbox**. Вектор: [kern.svg](../assets/kern.svg); значения цветов: [kern-theme.json](../assets/kern-theme.json). Первый нативный экран использует фон/поверхность/текст/янтарный акцент; полная интеграция знака и оформления ещё впереди.

| Назначение | Цвет |
|---|---|
| Фон / поверхность | `#1d2021` / `#282828` |
| Текст / вторичный | `#ebdbb2` / `#bdae93` |
| Акцент | `#fabd2f` |
| Граница | `#665c54` |
| Успех / ошибка | `#b8bb26` / `#fb4934` |

Плотный читаемый рабочий интерфейс: тонкие разделители, минимум рамок и повторных подписей, виджеты скрываются или сворачиваются. Мелкая сетка графика — соседние клетки с чуть разным фоном, без мелких линий. Крупные деления и время привязаны к отсчётам; перо совпадает с последней точкой кривой. Двойной ЛКМ ставит/убирает флаг; близкие кривые выбираются по расстоянию, неоднозначность даёт компактный выбор. Прозрачность только фона плашки, текст и управление чёткие; размытие пока отложено.

Палитра вдохновлена [Gruvbox](https://github.com/morhetz/gruvbox), исходники темы не включены. Свечение, постоянные анимации и декоративная нагрузка не являются целью; ресурсы проверяются на целевом слабом железе.
