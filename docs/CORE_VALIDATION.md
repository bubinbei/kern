## Воспроизведение

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace --locked
cargo build --workspace --release --locked
python tools/validate_core.py
```

Валидатор создаёт собственные профили в `target/qa/core-<дата>-<pid>/`, открывает только свои процессы/сокеты и сохраняет report.json. Работающие пользовательские профили, COM и внешние проекты не используются. Python-декодер независимо проверяет последовательность, CRC через zlib и формулу значений; Rust-reader не используется как единственный эталон.

Проверены 19 Rust-тестов и 18 сквозных сценариев: два отдельных источника, стабильные слоты, u64 без потери точности, повторы/конфликты пакетов, неверный пакет, свежесть без новых входов, revision настроек, предел IPC, эксклюзивность профиля, независимое чтение CRC, восстановленное качество, принудительное завершение ядра, отказ запуска при CRC, отдельная восстановленная копия, сохранность неполного хвоста, повторный запуск после восстановления и отзывчивый status при отказе диска. Детерминированная часть дала **27 пакетов / 459 показаний**.

Отказ записи моделируется запретом создания следующего сегмента; отдельный Rust-тест проверяет отравление писателя при ошибке записи. Это не физическое отключение диска и не доказательство обработки всех частичных sync-отказов. При обрезании каждого байта последней записи Rust-тест проверяет целый префикс и неизменность исходного файла.

## Осталось проверить/реализовать

- Windows 10 x64 на целевом слабом ноутбуке; точную модель Intel уточнить. Mac 2012/macOS — поздний этап.
- Длительная запись, частоты/масштаб нескольких источников, использование диска и восстановление большой истории.
- Полная отказная матрица C2: реальные/частичные ошибки синхронизации, потеря питания, отсутствующие сегменты и прерывание самой границы восстановления. Некоторые структурные ошибки сейчас дают безопасный отказ вместо автоматического продолжения.
- Раздельные права плагинов, подписки, надзор процессов/ограниченный restart; сейчас источники запускаются явно и не перезапускаются автоматически.
- Интерпретатор, карты/активация, физические параметры, рабочие форматы, резервная копия, обязательное меню и графики.

Готовность сборки, прохождение тестов и промышленная готовность — разные результаты. Следующий UI-компонент опирается на существующий контракт; он не должен скрывать перечисленные ограничения.
