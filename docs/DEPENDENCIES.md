# Зависимости ядра 0.1

Версии фиксируются в Cargo.lock. [Реестр](dependencies.json) создан из cargo metadata --locked; исходные уведомления сохранены в third_party/licenses и входят в локальный комплект. Копируются только открытые файлы лицензий официальных зависимостей.

| Группа | Для чего |
|---|---|
| serde / serde_json | Типизированные сообщения и собственные события журнала |
| crc32fast | Проверка случайного повреждения записи |
| getrandom | Новый локальный IPC-токен из генератора ОС |
| Остальные | Транзитивные/build/целевые зависимости перечисленных библиотек |

Для зависимостей выбирается разрешительная альтернатива MIT там, где она явно предложена. Это относится и к r-efi: строка MIT OR Apache-2.0 OR LGPL-2.1-or-later не означает обязательный выбор LGPL. У unicode-ident помимо MIT/Apache требуется Unicode-3.0, его текст также сохранён. Полный реестр включает и пакеты других целевых платформ, а не только связанные с Windows exe.

Новый код KERN — MIT. Rust standard library/toolchain имеют собственные условия; сборочный компилятор в комплект не включён. Перед внешней бинарной поставкой необходим отдельный обзор всей поставки, включая уведомления стандартной библиотеки. Сейчас создан локальный испытательный комплект, публичный бинарный релиз не опубликован.

Для отдельной нативной оболочки и границы COM плагина im2480 используются официальные `windows-sys`/`windows-link` (MIT-альтернатива); в headless-ядро они не входят. Web runtime/async-фреймворк не добавлены. Отсутствие браузерного движка не заменяет измерения CPU/RAM/GPU/диска и проверку Windows 10.

Прототип добавляет **redb 4.1.0** (MIT-альтернатива) для локального журнала и **uPlot 1.6.32** (MIT) для графиков. JS/CSS/LICENSE получены из официального npm-архива с проверкой SHA-512; артефакты и SHA-256 — `third_party/uplot-1.6.32/source.json`. Уведомления входят в новый комплект. Установленный Edge/Chrome — внешний runtime; он не копируется в поставку. Playwright используется только для разработки/проверки и не включён в runtime.

Для точной передачи калиброванных f64 включена возможность `serde_json/float_roundtrip`; регрессия проверяет побитовое совпадение на 65536 кодах. Без неё строгая проверка результата могла отвергать корректное значение после JSON-обмена.
