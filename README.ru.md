# KERN · Керн

**Независимая регистрация параметров бурения. Небольшое ядро Rust, сменные плагины, сохранность измерений.**

Начинаем с устойчивого ядра без GUI. Источники оборудования, интерпретатор и рабочие форматы подключаются отдельными компонентами; обязательный восстановительный журнал продолжает сохранять входы при отказе расчёта или интерфейса.

[Архитектура](docs/ARCHITECTURE.md) · [Этапы и приёмка](docs/ROADMAP.md) · [Стиль](docs/BRANDING.md) · [Происхождение материалов](docs/MATERIALS.md)

| Часть | Ответственность |
|---|---|
| Ядро | Каналы, параметры, качество, версии настроек, журнал и надзор |
| Плагины источников | Свой протокол оборудования; один COM-порт на экземпляр |
| Интерпретатор | Сырые данные → параметры по историческим картам калибровки |
| Плагины записи | Рабочие файлы, экспорт и дополнительная резервная копия |
| Системная оболочка | Обязательный отдельный процесс: меню, настройки, статусы |
| Графики | Заменяемое представление; нагрузка не определяет частоту регистрации |

**Состояние: до альфы, архитектура согласована, реализация ядра ещё не начата.** Этот репозиторий не содержит готового приложения или принятых замеров производительности. Первая целевая платформа — Windows 10 x64. Проверка на слабом ноутбуке с Intel «4125» и поздняя проверка macOS на Mac 2012 запланированы; поддержка не заявлена.

До альфы приоритет — рабочие проверяемые срезы. Подробная пользовательская помощь появится после стабилизации поведения. Утверждены трёхслойный знак и янтарный Ember / Gruvbox; оформление приложения впереди.

```powershell
python tools/project_context.py start core
python tools/docs_sync.py check
python tools/project_context.py check
python -m unittest discover -s tests -v
```

Нужны Python 3.10+ и Git; pip-зависимостей у инструментов нет. Корень можно открыть как Obsidian vault. Русский оригинал и английский перевод живут в одной ветке.
