# KERN · Керн

**Независимая регистрация параметров бурения. Небольшое ядро Rust, сменные плагины, сохранность измерений.**

Реализован первый срез ядра 0.1.0 и отдельная нативная оболочка Windows с меню, настройками и управлением пакетами: отдельный процесс, проверка сырых пакетов, журнал с CRC и подтверждением диска, восстановление, состояние и настройка свежести. Источники оборудования, интерпретатор и рабочие форматы подключаются отдельными компонентами; обязательный восстановительный журнал продолжает сохранять входы при отказе расчёта или интерфейса.

[Понятное руководство ядра](docs/CORE_GUIDE.md) · [Проверки](docs/CORE_VALIDATION.md) · [Архитектура](docs/ARCHITECTURE.md) · [Этапы и приёмка](docs/ROADMAP.md) · [Стиль](docs/BRANDING.md) · [Происхождение материалов](docs/MATERIALS.md)

| Часть | Ответственность |
|---|---|
| Ядро | Каналы, параметры, качество, версии настроек, журнал и надзор |
| Плагины источников | Свой протокол оборудования; один COM-порт на экземпляр |
| Интерпретатор | Сырые данные → параметры по историческим картам калибровки |
| Плагины записи | Рабочие файлы, экспорт и дополнительная резервная копия |
| Системная оболочка | Обязательный отдельный процесс: меню, настройки, статусы |
| Графики | Заменяемое представление; нагрузка не определяет частоту регистрации |

**Состояние: первый desktop-срез до альфы.** 26 Rust-тестов, 17 проверок im2480 и ранее 18 raw-сценариев / 14 проверок оболочки на Windows11: сбой/зависание UI не прерывают запись, штатное закрытие не вызывает respawn. Интерпретатор, карты, проверка физических приборов, универсальный SDK и длительная/слабая аппаратная приёмка ещё впереди. [Пакеты и надзор](docs/PLUGINS.md).

Сборка: `cargo build --workspace --release --locked`. Запуск: `target/release/kern-core.exe serve --profile runtime/first-test`; в другом окне `target/release/kern-demo.exe --profile runtime/first-test`. Локальный комплект с CMD-запусками создаётся `python tools/package_core.py` в `dist/Kern-Core-0.1.0/`.

По запросу владельца ведём подробное руководство ядра для неспециалиста; помощь по меняющемуся UI до альфы отложена. Оболочка подключена: после упаковки запускайте `Start-Kern.cmd`; для headless остаётся `Start-Core.cmd`. Отдельно запланирован веб конструктор виджетов для оператора без программирования, ответственные плагины остаются Rust. Утверждены три слоя и Ember/Gruvbox; полное оформление впереди. [Зависимости и уведомления](docs/DEPENDENCIES.md).


Первый COM-плагин **im2480** подключён: отдельный процесс, шесть каналов на модуль, проверка CRC и независимые пропуски. В локальном комплекте — пакет `plugins/im2480`; [контракт и проверка](docs/IM2480.md). Физическое оборудование ещё не принято.

```powershell
python tools/project_context.py start core
python tools/docs_sync.py check
python tools/project_context.py check
python -m unittest discover -s tests -v
```

Нужны Python 3.10+ и Git; pip-зависимостей у инструментов нет. Корень можно открыть как Obsidian vault. Русский оригинал и английский перевод живут в одной ветке.
