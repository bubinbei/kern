# KERN · Керн

**Независимая регистрация параметров бурения. Небольшое ядро Rust, сменные плагины, сохранность измерений.**

Реализован первый срез ядра 0.1.0 без GUI: отдельный процесс, проверка сырых пакетов, журнал с CRC и подтверждением диска, восстановление, состояние и настройка свежести. Источники оборудования, интерпретатор и рабочие форматы подключаются отдельными компонентами; обязательный восстановительный журнал продолжает сохранять входы при отказе расчёта или интерфейса.

[Понятное руководство ядра](docs/CORE_GUIDE.md) · [Проверки](docs/CORE_VALIDATION.md) · [Архитектура](docs/ARCHITECTURE.md) · [Этапы и приёмка](docs/ROADMAP.md) · [Стиль](docs/BRANDING.md) · [Происхождение материалов](docs/MATERIALS.md)

| Часть | Ответственность |
|---|---|
| Ядро | Каналы, параметры, качество, версии настроек, журнал и надзор |
| Плагины источников | Свой протокол оборудования; один COM-порт на экземпляр |
| Интерпретатор | Сырые данные → параметры по историческим картам калибровки |
| Плагины записи | Рабочие файлы, экспорт и дополнительная резервная копия |
| Системная оболочка | Обязательный отдельный процесс: меню, настройки, статусы |
| Графики | Заменяемое представление; нагрузка не определяет частоту регистрации |

**Состояние: первый headless-срез до альфы.** Проверены 19 Rust-тестов и 18 сквозных сценариев на Windows11. Ядро около 1 МиБ; короткий замер простоя — около 4,3 МиБ рабочей памяти. Это предварительные наблюдения, не приёмка Windows10, слабого железа или 24–72 часов. Интерпретатор, карты, физические параметры, надзор плагинов и графическое меню ещё не реализованы.

Сборка: `cargo build --workspace --release --locked`. Запуск: `target/release/kern-core.exe serve --profile runtime/first-test`; в другом окне `target/release/kern-demo.exe --profile runtime/first-test`. Локальный комплект с CMD-запусками создаётся `python tools/package_core.py` в `dist/Kern-Core-0.1.0/`.

По запросу владельца ведём подробное руководство ядра для неспециалиста; помощь по меняющемуся UI до альфы отложена. Следующий обязательный компонент — отдельная оболочка с меню/настройками. Утверждены три слоя и Ember/Gruvbox; интеграция оформления впереди. [Зависимости и уведомления](docs/DEPENDENCIES.md).

```powershell
python tools/project_context.py start core
python tools/docs_sync.py check
python tools/project_context.py check
python -m unittest discover -s tests -v
```

Нужны Python 3.10+ и Git; pip-зависимостей у инструментов нет. Корень можно открыть как Obsidian vault. Русский оригинал и английский перевод живут в одной ветке.
