Прочитать AGENTS.md и start core. Задачу сформулировать как результат + ограничения + приёмка + нужные файлы. Реализовать один сквозной срез по docs/ROADMAP.md, не загружать старые журналы без зависимости. При изменении контракта обновить только нужную пару RU/EN. До альфы не расширять пользовательскую помощь. Сохранять независимый эталон и отделять build от поведения/нагрузки/оборудования. После завершения record/check; для публикации просмотреть происхождение, весь новый diff и фактическую удалённую ревизию.

Упоминания стороннего интерфейса в разговоре переводить в конкретные требования к KERN, без названий, ссылок и расшифровки прозвищ. «Белая» — разговорный ориентир; при необходимости письменного контекста использовать «программа с белым интерфейсом». Не подменять этим проверку происхождения материалов.
