# KERN — рабочие правила

Перед задачей: `python tools/project_context.py list`, затем `start core`. Прочитать только STATE/RECENT и один указанный skill; остальные источники по зависимости. Контекст: context/README.md. Требования: docs/ARCHITECTURE.md; этапы/проверки: docs/ROADMAP.md.

- Приоритет до альфы — законченный рабочий срез и достаточные проверки. Подробную помощь, описание меняющегося UI и их переводы отложить. Краткие контракты, ограничения, сохранность и доказательства обязательны.
- План не реализация; успешный build не аппаратная/длительная/ресурсная приёмка. Следующий шаг C0–C1, без расширения платформ или косметики.
- Не импортировать историю, runtime-код, исследования, бинарники, частные спецификации, профили или реальные измерения из других проектов. Публичная граница: docs/MATERIALS.md. Не добавлять названия/ссылки сторонних прикладных программ без необходимости и отдельного решения владельца.
- Сохранять пользовательские правки/рабочие процессы. Без отдельной задачи не трогать приборы, COM, рабочие файлы и старые профили. Новый тракт использует отдельный синтетический профиль и версию журнала.
- Ядро владеет состоянием/версиями/журналом. UI и зависший плагин не останавливают сырой журнал. Очереди, время обработки и автоматические перезапуски ограничены; качество и потери явные.
- Русский канон docs/ и README.ru.md, английский docs/en/ и README.md — одна ветка. Менять только затронутые пары; после смысловой сверки `tools/docs_sync.py record --source <file>`, затем check. Не подтверждать непроверенные переводы.
- После задачи обновить STATE (до 2500 символов) и один раунд через `project_context.py record core --input <json>`; RECENT генерируется, прошлые записи не переписываются. В запросе следующего шага: цель, ограничения, приёмка, нужные файлы; историю не повторять.
- Перед публикацией проверить происхождение, diff/индекс/историю, ссылки, docs/context и профильные тесты. Не force-push и не переписывать историю без явного решения. После push сверить SHA каждой площадки и фактическую видимость; не скрывать частичную поставку.
